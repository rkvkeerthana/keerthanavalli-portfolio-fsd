# React Application

A modern React application built using Vite, TypeScript, Tailwind CSS, and modern frontend technologies.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- Motion Animation Library
- Express.js
- Node.js
